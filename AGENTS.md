# Agent Instructions

Before doing anything in this repository, read [`RULE.md`](RULE.md) in full and follow it. It is binding for every AI agent and every tool.

The rule most often missed: **the app ships on both Android and iOS.** Every change, plan and recommendation must work on both platforms, and every report must say which platforms it was actually run on. See "Cross-Platform Rule (Android + iOS)" in `RULE.md`.
